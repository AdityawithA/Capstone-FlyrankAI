## Prompt for feature branch 2

Build a responsive Settings page using React.

Requirements:

Files:
- Settings.jsx
- Settings.css

The page must include:

- Full Name
- Email Address
- Theme selector
- Save button

Validation:

- Name required
- Email required
- Email format validation
- Disable Save button until valid

Accessibility:

- Proper labels
- Keyboard navigation
- aria-invalid for invalid inputs

Behaviour:

- Show validation messages
- Show success message after saving

Code Style:

- Functional components
- React Hooks
- Clean reusable functions

Verification:

After writing the code:

1. Review it for bugs.
2. Check accessibility.
3. Check responsiveness.
4. Explain any assumptions.

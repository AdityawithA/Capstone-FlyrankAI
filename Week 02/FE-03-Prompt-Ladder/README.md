# FE-03: Prompt Ladder

This folder contains the deliverables for the FlyRank AI Internship Week 2 FE-03 assignment.

## Objective

Compare the effect of improving an AI prompt one layer at a time while observing how each change influences the generated output.

## Deliverables

- Prompt ladder
- Output comparison
- Final reusable prompt

## Learning Outcome

Small, measurable prompt improvements produce more reliable AI-generated code than changing multiple variables simultaneously.

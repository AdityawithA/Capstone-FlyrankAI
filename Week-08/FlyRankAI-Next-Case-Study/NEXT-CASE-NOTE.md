# How to Add My Next Portfolio Case Study

## Next case: InterviewAce AI

My next portfolio case study will be **InterviewAce AI**, an AI-powered interview preparation platform I built with Flask, Python, an LLM API, SQLite, authentication, response storage, performance tracking, and deployment.

I will reuse the Week 2 three-beat structure for the case study:

### 1. Problem
Interview preparation can be repetitive and difficult to personalize. Candidates need realistic practice and useful feedback rather than only static interview questions.

### 2. What I did
I built InterviewAce AI as a web application that generates role-specific interview practice and uses an LLM to evaluate responses. I also implemented authentication, response storage, performance tracking, and a deployed application flow.

### 3. What came of it
The result is a working AI-focused portfolio project that demonstrates more than a UI: it shows API integration, backend development, data persistence, user flows, AI-assisted evaluation, and deployment.

## How I will add the case

1. Add an **InterviewAce AI** project/case-study entry to the portfolio.
2. Use one strong screenshot or project visual.
3. Lead with the problem instead of the technology list.
4. Explain my specific implementation decisions.
5. Include the live demo and GitHub repository.
6. Add one measurable or verifiable result where I have evidence.
7. End with what I learned and what I would improve next.

## Evidence rule

I will only claim technologies, metrics, results, or implementation details that I can verify from the project. Unknown metrics will not be invented.

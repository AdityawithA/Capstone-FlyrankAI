# AI Prompts Used During Development

This document records the AI prompts used during the development of **CineVault**, a React-based movie and TV-show discovery application.

AI was used as a development assistant for planning, implementation, debugging, UI refinement, accessibility review, and code review.

---

## 1. Project Planning

```text
Act as a senior React developer.

I need to build a movie and TV discovery application called CineVault.

The application should allow users to:

- Browse movies and TV shows
- Search for titles
- View posters, titles, release years, and media types
- View additional information about a title
- Add and remove titles from favourites
- View saved favourites
- Persist favourites using localStorage

Before writing the complete application, create an implementation plan.

Include:

1. Component architecture
2. Folder structure
3. State management approach
4. API integration approach
5. Favourites persistence strategy
6. Loading and error states
7. Empty states
8. Responsive UI strategy
9. Accessibility considerations

Do not generate the entire application yet.

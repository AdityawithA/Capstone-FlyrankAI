This capstone creates a repeatable, low-friction workflow for adding the next real project to a portfolio without rebuilding the portfolio from scratch.

## How to add the next case

1. Open the portfolio repository.
2. Find the main projects/case-studies data or section.
3. Add a new case-study entry using the three-beat structure in `portfolio/NEXT_CASE_STUDY.md`.
4. Add the project title, one-sentence outcome, stack, live link, and repository link.
5. Add one representative screenshot or project visual.
6. Keep the entry concise; the portfolio should summarize the work and link to the full case study.
7. Run the portfolio locally and verify the new card/detail page.
8. Commit and deploy the portfolio update.
9. Verify the live portfolio link after deployment.

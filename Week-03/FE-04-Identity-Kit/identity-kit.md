# Identity Kit — Aditya Kumar

## Typography

### Primary Font
**Inter**

Inter is used throughout the portfolio for headings, body text, navigation, buttons, labels, and project content.

### Font Weights
- 700 — Hero and major headings
- 600 — Section headings and project titles
- 500 — Buttons, labels, and navigation
- 400 — Body text and descriptions

Using one font family keeps the portfolio consistent and professional.

---

## Color Palette

| Role | Hex Code | Usage |
|---|---|---|
| Primary Blue | `#2563EB` | Main CTA buttons, links, active states |
| Near-Black | `#111827` | Headings and primary text |
| Near-White | `#F9FAFB` | Main page background |
| Teal Accent | `#14B8A6` | Small highlights and secondary accents |

### Color Rules

- Keep the palette limited to these four colors.
- Use blue primarily for actions and links.
- Use teal sparingly.
- Use near-black for readable text.
- Keep the background calm and clean.
- Do not introduce unnecessary colors.

## Style Note

**Inter with near-black text on a near-white background, using blue for primary actions and a restrained teal accent.**

**The mood is clean, technical, confident, and minimal; the design frames the projects rather than competing with them.**

---

## Design Rules

1. Use Inter consistently.
2. Keep the four-color palette restrained.
3. Use generous whitespace.
4. Keep buttons and interactive elements visually clear.
5. Avoid unnecessary gradients.
6. Keep animations subtle and purposeful.
7. Let real project screenshots and case studies be the visual focus.
8. Maintain consistent typography and colors across every page.

---

## Claude Project Standing Instruction

Use this as a permanent instruction for the portfolio project:

> Use Inter throughout the portfolio. Use #111827 for text, #F9FAFB for the background, #2563EB for primary actions and links, and #14B8A6 only as a restrained accent. Keep the visual style clean, technical, confident, and minimal. Use generous whitespace and consistent typography. Avoid unnecessary gradients, excessive animations, extra fonts, and decorative elements. The design should frame the real projects rather than compete with them.

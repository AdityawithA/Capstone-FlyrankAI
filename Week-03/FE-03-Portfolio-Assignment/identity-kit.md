# Week 3 — Visual Identity Kit

## Direction
**Mood:** calm, technical, confident, modern.

The interface frames the work instead of competing with it.

## Typography
**Inter** for headings, body, navigation, labels, buttons, and project metadata.

Weights:
- 700 — major headings
- 600 — section headings/project titles
- 500 — buttons/labels
- 400 — body text

## Palette
| Role | Hex | Usage |
|---|---|---|
| Near-black | `#111827` | Primary text |
| Near-white | `#F9FAFB` | Background |
| Primary blue | `#2563EB` | Links and main CTA |
| Teal accent | `#14B8A6` | Small accents only |

## Spacing
8px, 16px, 24px, 48px, and 80–120px section spacing.

## Logo
Use the included `logo.svg` and `favicon.svg` as the AK monogram identity.

## Style Note
**Inter, near-black on near-white, with blue as the primary action color and a restrained teal accent.**

**The mood is calm, technical, and confident; the interface stays quiet so the real projects remain the most memorable thing on the page.**

## AI Workspace Instruction
Keep the portfolio calm, technical, confident, and minimal. Use Inter throughout. Use #111827 for primary text, #F9FAFB for the background, #2563EB for primary actions/links, and #14B8A6 only as a restrained accent. Keep generous whitespace and consistent spacing. Do not add decorative gradients, excessive animations, extra fonts, or competing colors. Real project screenshots must remain the visual focus.

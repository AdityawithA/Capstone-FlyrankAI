# AI Image Prompts — Week 3

## Hero Texture

Create a minimal abstract visual for a professional software developer portfolio.

Use a near-black background with restrained electric blue and subtle teal accents. Create soft geometric forms, very subtle depth, clean negative space, and a premium technical atmosphere.

No text, no logos, no people, no devices, no dashboards, no fake application UI, no stock-photo appearance.

The visual should work as a quiet background behind portfolio content and should never compete with project screenshots.

---

## Optional Secondary Texture

Create a minimal abstract technical texture using the same visual language as the hero.

Near-black foundation, subtle blue illumination, very small teal accents, clean geometric structure, soft depth, generous negative space, premium and restrained.

No text, no people, no UI, no objects, no logos.

The image must look like it belongs to the same visual identity as the hero texture.

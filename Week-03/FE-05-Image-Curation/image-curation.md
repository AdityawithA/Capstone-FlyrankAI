## Real Capture vs AI Decision

### Real captures

I chose real captures for all project work because screenshots are stronger evidence than generated representations.

Real captures are used for:

- InterviewAce AI
- CampusSync
- TypeRush
- SMS Spam Detection
- Breast Cancer Detection
- Dezinova

### Real photograph

A real profile photograph is used because the image represents an actual person.

### AI-generated visual

AI is used only for a subtle connective hero texture where there is no actual project interface to show.

---

## Rejected AI Image

I rejected a generated futuristic AI dashboard illustration because it looked impressive but did not represent any application I actually built.

It would make the portfolio look more polished at first glance but would weaken the credibility of the project proof.

I chose the real InterviewAce AI screenshot instead because it shows the actual product.

---

## Image Style

All connective AI-generated visuals should share one visual language:

- Dark/near-black foundation
- Soft blue primary glow
- Small teal accent
- Minimal geometric forms
- Lots of negative space
- No text
- No people
- No fake UI

The images should feel like part of the same portfolio rather than a collection of unrelated AI generations.

---

## Curation Rules

1. Real work always beats an AI stand-in.
2. A real photo is always used when the subject is me.
3. AI visuals are used only where they add context.
4. Generated visuals must share one consistent style.
5. Screenshots must be clean and readable.
6. Avoid unnecessary decorative images.
7. Never fabricate project results, metrics, or interfaces.

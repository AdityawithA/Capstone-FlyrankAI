WHY THIS SCENE

One meaningful interaction, not decoration.

The core combines a central sphere, transparent shell, signal rings and orbiting nodes. Material switching changes the visual language while wireframe mode exposes the geometry.

PERFORMANCE

Small geometry. No external model.

The scene uses procedural geometry, lazy initialization, capped pixel density and a reduced-motion/static fallback instead of shipping a large model.

FE-10 LENS

Performance note

The main cost is the WebGL canvas. This build avoids a large model download, limits device pixel ratio, uses simple geometry and pauses rendering when the scene is outside the viewport.

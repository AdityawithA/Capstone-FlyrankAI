# Week 09 — Break Your Own Site

A hardened portfolio exercise for the FlyRank AI internship track.

## Goal

This project deliberately tests the portfolio beyond the happy path:

- responsive/mobile behavior
- keyboard navigation
- external links
- SEO and social metadata
- reduced-motion behavior
- basic security hygiene
- findability and performance readiness

## Files

```text
Week-09-Break-Your-Own-Site/
├── index.html
├── style.css
├── script.js
├── HARDENING-REPORT.md
├── FIX-LOG.md
├── README.md
└── .gitignore
```

## Run locally

Because this is a static site, serve the folder with any static HTTP server.

For example:

```bash
python -m http.server 8000
```

Open:

```text
http://localhost:8000
```

## Deployment

The site can be deployed to Netlify, Vercel, GitHub Pages, or another static host.

## Important

The assignment requires real Lighthouse/WAVE evidence. The included report provides the test plan and documents the implemented fixes, but **real audit scores must be added after testing the deployed URL**.

01

Motion choices

The button uses transform and opacity for the main movement, avoiding layout-heavy animation. Loading lasts long enough to communicate progress, success uses a short check transition, and error uses a single shake.

02

Interruptible by design

Repeated triggers do not leave competing timers behind. A new run clears the previous lifecycle before starting a fresh one.

03

Reduced motion

When the operating system requests reduced motion, movement is minimized rather than removing feedback. State, labels, color, and icons remain visible.
